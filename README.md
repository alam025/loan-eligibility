## 🚀 About

> **Trained model with 92% accuracy and bias auditing across protected demographic attributes**

**Loan Eligibility Predictor** is a production-ready **FinTech** project built with **Python, scikit-learn, FastAPI, React**.
Deployed on **Render** with full CI/CD pipeline.
